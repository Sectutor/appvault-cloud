❓ FAQ

Everything you need to know before downloading.

Do I need to know Docker or the command line?
Absolutely not. AppVault installs and manages Docker for you completely. You never need to open a terminal or write a single command. Just click install and your app runs.
What are the system requirements?
AppVault runs on Windows 10/11, macOS 12+, and Ubuntu 20.04+. Most AI apps work best with 16GB RAM and an NVIDIA GPU, but many lighter apps (like n8n or Nextcloud) work fine on basic hardware.
Is my data private?
Yes — 100% private. All apps run locally on your machine. No data is sent to any cloud. AppVault itself only checks for updates and validates your license key. Your AI conversations, images, and files never leave your computer.
What's the difference from just using Docker Compose?
AppVault gives you a beautiful GUI, pre-configured Docker Compose files, automatic port management, one-click updates, and a catalog of vetted apps. It saves hours of setup time and eliminates the "works on my machine" problem.
How does the Pro license work?
After purchase you get a license key via email instantly. One license = one server. Enter it in AppVault and all 40+ apps unlock with unlimited installs. Need more servers? Buy another license — each one binds to a different machine.
What does the Free tier include?
Free users see the full 40+ app catalog (same as Pro). The install limit is set by the admin — you can browse everything and install up to the admin-defined cap. Upgrade to Pro to remove the cap and get unlimited installs.
Can I get a refund?
Yes. We offer a 30-day money-back guarantee. If AppVault doesn't work for you, email us within 30 days of purchase for a full refund — no questions asked.
Can I use it on multiple machines?
Self-Host Pro covers one server per license. Buy a license for each machine you want to run AppVault on. Each license key binds to the first server that activates it. Managed (hosted) is coming Q4 2026.
